# Brainstorming: 2D Developer Portfolio

## Overview
- **Type**: Portfolio / Landing Page
- **Tech Stack**: Vite (React) + Vanilla CSS + Framer Motion
- **Vibe/Style**: Dark Mode, Glassmorphism, Neon Accents, Cyberpunk / Hacker vibe.
- **Avatar Style**: Chibi / Hoạt hình.

## Sections
1. **Hero Banner**: Chứa Avatar 2D ở giữa, các element như bàn phím, màn hình, chuột lơ lửng xung quanh (Framer Motion).
2. **About Me**: Giới thiệu ngắn, kỹ năng chuyên môn.
3. **Projects**: Các dự án nổi bật (Glassmorphism Cards).
4. **Experience/Education**: Quá trình làm việc.
5. **Contact**: Thông tin liên hệ và mạng xã hội.
