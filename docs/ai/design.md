# Design System V2 (Editorial 3D Generative)

## Global Theme
- **Background**: #030712 (Very Deep Navy / Black)
- **Background Pattern**: Subtle topographical lines overlay (opacity 5%)
- **Text**: #f8fafc (Slate 50) - White/Off-white
- **Accents**: #3b82f6 (Blue), #ef4444 (Red), #10b981 (Green) based on image context.
- **Borders**: 1px solid rgba(255, 255, 255, 0.05) or rgba(255, 255, 255, 0.1)

## Typography
- **Headings (Hero, Large titles)**: 'Playfair Display', serif. Extremely large, elegant, often uppercase or title case.
- **Subheadings/Tags**: 'Inter', sans-serif. Very small (0.75rem), uppercase, wide letter-spacing (2px - 4px).
- **Body**: 'Inter', sans-serif, lightweight (300).

## Layout & Grid
- Extensive use of CSS Grid.
- Thin dividing lines between sections and columns.
- Minimalistic, lots of padding/margin (whitespace).
- Asymmetrical arrangements for images and text blocks.
