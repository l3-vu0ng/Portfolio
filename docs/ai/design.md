# Design System

## Global Theme
- **Background**: #0f172a (Deep Slate / Dark Blue)
- **Text**: #f8fafc (Slate 50)
- **Primary / Neon**: #0ea5e9 (Cyan) / #8b5cf6 (Purple)
- **Glassmorphism**: 
  - Background: rgba(255, 255, 255, 0.05)
  - Border: rgba(255, 255, 255, 0.1)
  - Backdrop Blur: 10px

## Typography
- **Font Family**: 'Inter', sans-serif, 'Fira Code' for code elements.

## Animations (Framer Motion)
- **Floating**: y: [0, -20, 0], transition: { repeat: Infinity, duration: 4, ease: "easeInOut" }
- **Hover**: scale: 1.05, box-shadow: "0 0 15px rgba(14, 165, 233, 0.5)"
